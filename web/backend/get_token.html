🔐 TripRaft Admin Access

Get your Firebase authentication token to access admin endpoints

1 What You Need
✅ Be logged in to TripRaft frontend
✅ This page open in the same browser
✅ Backend server running at localhost:5001
2 Get Your Token
Click the button below to automatically get your Firebase authentication token. The token will be copied to your clipboard.
3 Use Your Token
Once you have your token, you can access admin endpoints:
GET /api/expense/performance/report?date=2025-11-20
GET /api/expense/performance/slow-operations
GET /api/expense/performance/costs?date=2025-11-20
GET /api/expense/cache/stats
POST /api/expense/cache/clear-all
curl -H "Authorization: Bearer YOUR_TOKEN" \ http://localhost:5001/api/expense/performance/report
4 Token Expiration
⚠️ Firebase tokens expire after 1 hour.
If you get authentication errors, come back here and get a new token.
